# 第一版架构

`streamlit_app.py` → `app.agent.graph.run_audit()` → 解析 → 标签字段抽取 → 制度规则检索 → 确定性业务检查 → 结构化报告。

## 已完成

- 电子PDF、TXT、DOCX、XLSX文本解析；字段附原文和页码。
- 标签匹配基线；缺失字段进入人工复核。
- 两条虚构差旅制度；按城市选择条款并绑定引用。
- 必备材料、金额一致性、日期范围、一晚住宿上限、主体一致性五项检查。
- Streamlit界面、两组端到端样例与单元测试。

## 后续迭代

真实OCR、多模态模型、生产级向量RAG、LangGraph持久化状态、更多业务规则及更大规模评测集仍属于后续迭代。

当前`graph.py`使用固定节点顺序和LangGraph兼容的字典状态；切换到LangGraph时可逐节点复用`nodes.py`。
